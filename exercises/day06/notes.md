1. show 定义在顶层，它读的是自己定义位置的 name。run 里的 name 是另一份局部变量，跟 show 没关系。这就是词法作用域：看代码写在哪，不看谁调用。
2. createStore()闭包实现，每次调用都会创建一个新的闭包，所以不会共享状态
3. 闭包藏状态：每个实例一套函数（内存 × 实例数），但真私有。
#x：私有字段 + 原型上共享一份方法，实例多时更省内存。
取舍：实例少、偏函数式 → 闭包；实例多、偏类风格 → #x。
4. fn.length 只数"默认参数之前"的形参，rest 不算。所以 curry 遇到带默认参数的函数会提前执行，把后面的参数丢成 undefined。
