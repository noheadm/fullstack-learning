目的：你已有 `electron-demo`（TS + Electron 打包）、`node-demo`、`Test4debounce`、`Test4throttle` 等产物。Phase 1 的 Day 1–12 里有你已经会的内容，不该用 2h/天 重学一遍。

规则：

- 只给自己 30 分钟，不许查资料、不许问 AI。
- 每题写完，把代码放进 `exercises/跳级测试/`，每题一个文件。
- 写不出来就写"卡在哪一行、为什么"，不许跳过。

## 题 1：debounce（10 分钟）

写 `debounce(func, delay = 500)`，要求：

1. 返回的函数支持 `.cancel()`，调用后待执行的调用作废。
2. 保留 `this` 和全部参数。
3. 顺手写 `throttle(func, interval)`，行为：首次立即执行，interval 内后续调用合并到末尾补一次。

自测：用 3 个按钮或 3 次连续调用打印时间戳，证明"连续 5 次触发只执行 1 次"和"cancel 后 0 次执行"。

## 题 2：deepClone（12 分钟）

不用 `JSON.parse(JSON.stringify(x))`，手写深拷贝，必须支持：

1. 循环引用（`obj.self = obj`）。
2. `Date`、`Map`、`Set`、数组。
3. 函数和 Symbol 按引用复制即可，但要说明理由。

自测：造一个含循环引用 + Map + Date 的对象，拷贝后改原对象，打印证明互不影响。

## 题 3：事件循环（8 分钟）

写出下面代码的输出顺序（不许运行，先写答案再运行验证）：

```js
console.log('A');
setTimeout(() => console.log('B'), 0);
Promise.resolve().then(() => console.log('C'));
queueMicrotask(() => console.log('D'));
(async () => { console.log('E'); await null; console.log('F'); })();
console.log('G');
```

再回答：`process.nextTick` 在浏览器里存在吗？宏任务和微任务的执行顺序谁先？
