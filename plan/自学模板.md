# 自学模板（极简版）

## 你只需要回一次

复制这三行，填空，发我：

```
想学：____
会一点：____      （零基础就写"没有"）
学完要做到：____
```

就这样。后面全是我负责：拆顺序、查前置、写讲解、写测试、定验收。你不用确认、不用审大纲、不用回第二遍。

## 我收到后直接做完这些

1. 判断你有没有缺前置（缺就直接在第一批材料里补，不额外问你）
2. 排出线性顺序（概念先定义后使用，难度不跨档）
3. 一次交 2–3 项：每项 = 现象 → 讲解 → 可运行例子 → 测试 → 常见坑 → 验收
4. 每项的代码例子我都会实际跑过
5. 你做完一项，我验测试 + 笔记 + commit，然后给下一项

## 我默认的假设（你可以不写）

- 零基础，除非你说"会一点"
- 单次 2 小时
- 产出优先：每 3–4 项必须做出一个能跑的东西
- 不夹带面试题和进阶技巧

## 我发现内容不线性时

我自己修，不找你确认。只有两种情况会来问你：

1. 需要你选方向（比如"想做网页还是想做命令行工具"）
2. 你卡在同一项超过 4 小时

## 你做完一项要发的（就这一行）

```
0-3 绿了 10/10，commit 3f2a1c
```

笔记我会自己看，不用你贴。
