# 术语与报错对照（查词用）

这份文件只用来查词，不是学习内容。报错原文是 JS 引擎输出的英文，无法翻译，但每条都能对应到一句中文意思。

## 一、常见报错

| 英文原文 | 中文意思 | 通常原因 |
|----------|----------|----------|
| `ReferenceError: x is not defined` | 变量 x 不存在 | 拼错、忘了 `const`/`let`、作用域外访问 |
| `ReferenceError: Cannot access 'x' before initialization` | 声明前就访问了 x | `let`/`const` 的 TDZ |
| `TypeError: Assignment to constant variable` | 给常量重新赋值 | 对 `const` 用 `=` |
| `TypeError: Cannot read properties of undefined (reading 'x')` | 读 `undefined` 上的 `x` | 中间某层属性不存在 |
| `TypeError: x is not a function` | x 不是函数 | 拼错、没导出、拿到的是值不是函数（`fn` vs `fn()`） |
| `TypeError: Reduce of empty array with no initial value` | 空数组且没给初始值 | `[].reduce(fn)` 缺第二个参数 |
| `TypeError: Cannot mix BigInt and other types` | BigInt 不能和普通数字混算 | `1n + 1` |
| `TypeError: Class constructor X cannot be invoked without 'new'` | 类必须用 new 调用 | 把 class 当普通函数调用 |
| `SyntaxError: Unexpected token` | 出现了不该出现的符号 | 少括号、少引号、中文标点 |
| `SyntaxError: Unexpected end of input` | 输入意外结束 | 少一个右括号或右引号 |
| `SyntaxError: Private field '#x' must be declared in an enclosing class` | 私有字段只能在类内部访问 | 在类外用 `obj.#x` |
| `RangeError: Maximum call stack size exceeded` | 调用栈溢出 | 无限递归（常见于循环引用没处理） |
| `Uncaught (in promise)` | Promise 的拒绝没人处理 | 少了 `catch` 或 `try/catch` |
| `DataCloneError` | 数据不能克隆 | `structuredClone` 遇到函数 / Symbol |
| `AggregateError` | 多个错误的集合 | `Promise.any` 全部失败时抛出 |

## 二、常用术语

| 英文 | 中文 | 一句话 |
|------|------|--------|
| value / primitive | 值 / 原始值 | 不可变、按值比较（string、number 等） |
| reference | 引用 | 指向对象内存地址 |
| scope | 作用域 | 变量能生效的范围 |
| lexical scope | 词法作用域 | 看代码写在哪，不看谁调用 |
| hoisting | 提升 | 声明被移到作用域顶部 |
| TDZ | 暂时性死区 | `let`/`const` 声明前不可访问 |
| closure | 闭包 | 函数记住了定义时的环境 |
| mutable / immutable | 可变 / 不可变 | 内容能不能改 |
| shallow copy | 浅拷贝 | 只复制第一层 |
| deep copy | 深拷贝 | 递归复制所有层 |
| destructuring | 解构 | 按名字/位置取值并声明变量 |
| spread / rest | 展开 / 剩余 | `...` 的两种用途 |
| higher-order function | 高阶函数 | 接收或返回函数的函数 |
| callback | 回调 | 作为参数传进去的函数 |
| side effect | 副作用 | 函数除返回值外改变了外部状态 |
| currying | 柯里化 | 多参数变一次一个 |
| memoize | 记忆化 | 缓存计算结果 |
| debounce | 防抖 | 停止触发后才执行 |
| throttle | 节流 | 单位时间内最多执行一次 |
| prototype | 原型 | 实例共享属性所查的对象 |
| prototype chain | 原型链 | 一层层向上找属性 |
| instance | 实例 | 由构造函数/类创建的对象 |
| constructor | 构造函数 | 用来创建实例的函数 |
| enumerable | 可枚举 | 会不会出现在 `Object.keys` / `for...in` 里 |
| property descriptor | 属性描述符 | `writable`、`enumerable`、`configurable` |
| accessor | 访问器属性 | 由 `get`/`set` 定义的属性 |
| pending / fulfilled / rejected | 待定 / 成功 / 失败 | Promise 的三种状态 |
| thenable | 类 Promise 对象 | 带 `then` 方法的对象 |
| microtask / macrotask | 微任务 / 宏任务 | Promise.then 先于 setTimeout |
| coercion | 类型转换（隐式） | `"5" - 3` 得到 2 |

## 三、读报错的顺序

1. **第一行**：错误类型 + 原因，先看懂这句中文意思
2. **`at` 那一行**：文件路径 + `行:列`，直接去那一行
3. **`at` 往下几行**：调用链，看是谁调用了出错的地方
